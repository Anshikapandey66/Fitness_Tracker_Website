# 💪 FitTrack – Fitness & Wellness Dashboard

FitTrack is a modern and responsive **Fitness & Wellness Dashboard** built using **HTML, CSS, and JavaScript**. It helps users track their daily fitness activities, workouts, hydration, nutrition, and overall progress from one place.

## ✨ Features

* 🏠 **Dashboard** – View daily fitness statistics
* 👟 **Step Tracker** – Track daily steps and goals
* 🔥 **Calories Tracker** – Monitor calories burned
* 💧 **Hydration Tracker** – Track daily water intake
* 🏋️ **Workout Center** – Choose and start different workouts
* ⏱️ **Workout Timer** – Built-in workout timer
* 🍎 **Nutrition Tracker** – Add and track food calories
* 📈 **Progress Chart** – View weekly workout activity
* 🏆 **Achievements** – Fitness goals and milestones
* 🌙 **Dark Mode** – Switch between light and dark themes
* 💾 **Local Storage** – Fitness data remains saved after refreshing
* 📱 **Responsive Design** – Works on desktop, tablet, and mobile

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Chart.js
* LocalStorage

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Start tracking your fitness activities.
